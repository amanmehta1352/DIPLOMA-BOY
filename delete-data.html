अपना डेटा मिटाएँ · Delete your data

Diploma Boy

Diploma Boy में कोई खाता (account) नहीं बनता। आपकी प्रगति आपके फ़ोन में रहती है। अगर आपने बैकअप चालू किया है, तो उसकी एक copy server पर भी है। दोनों आप खुद मिटा सकते हैं।

Diploma Boy does not create any account. Your progress stays on your phone; if you turned on backup, a copy is also on the server. You can delete both yourself.

तरीका 1: ऐप के अंदर · Option 1: inside the app

ऊपर दाईं ओर Settings खोलें → बैकअप में बैकअप बंद करें (server की copy मिटाएँ) दबाएँ → फिर इस phone की प्रगति मिटाएँ दबाएँ → पक्का करें।

Open Settings (top right) → under Backup tap Turn off backup (clear the server copy) → then Erase progress on this phone → confirm.

तरीका 2: ऐप हटाएँ · Option 2: uninstall

फ़ोन से ऐप uninstall करें, या Settings → Apps → Diploma Boy → Storage → Clear data।

Uninstall the app, or go to Settings → Apps → Diploma Boy → Storage → Clear data.

क्या बचा रहता है · What remains

हमारे पास आपकी कोई निजी जानकारी (नाम, फ़ोन, ईमेल) नहीं है। बैकअप बंद करने के बाद server पर आपकी प्रगति नहीं रहती। अगर बैकअप code खो गया है, तो वह copy किसी से जुड़ी नहीं रहती: उसमें आपकी कोई पहचान नहीं होती और code के बिना हम भी उसे नहीं पहचान सकते।

We hold no personal information about you (name, phone, email). After you turn off backup, your progress is not kept on the server. If you lost your backup code, that copy is not linked to you: it holds nothing that identifies you, and without the code we cannot find it either.
